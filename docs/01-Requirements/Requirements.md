## Module Requirements
The following sections document the requirements that the motor system needs to fulfill in order for the project to be successful.

| **Requirement Description** | **Measure of<br> Threshold** | **Target<br>Measure** |**Stretch<br>Requirement<br>(Y-N)**|
|-----------------------------| ----------------- | ----------------- | :-----: |
| Surface mounted, 3.3V switching power regulatore | 3.2 Volts | 3.3 Volts | No |
| Surface mounted microcontroller | 1 PIC or ESP | 8-bit PIC | No |
| Wireless Communication | Able to send or receive a Wi-Fi data | Send and receive Wi-Fi Data to MQTT | Yes |
| Stepper Motor to rotate scope (x-axis) | Can precisely rotate a specified distance | 0.5 millimeters | No |
| Stepper Motor to rotate scope (y-axis) | Can precisely rotate a specified distance | 0.5 millimeters | No |
| Motor Driver | Needed to power motors | Motors recieve enough power | No |
