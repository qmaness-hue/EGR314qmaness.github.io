## Overview

This schematic is designed to support a dual motor system driven by two separaate motor drivers controlled by an ESP32 microcontroller. All components are powered by a voltage regulator that converts 8-12 volts into 3.3 volts. The microcontoller of this system has UART connections that go to the other subsystems' microcontollers.
